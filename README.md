# DSA-basics-to-advanced

A comprehensive collection of Data Structures and Algorithms problems, starting from basic conditional logic to array manipulation techniques.

**Note:** Each problem file contains comprehensive documentation above the code including algorithm explanation, time/space complexity, examples, and edge cases.

- [CheckEvenOdd.java](src/1.%20if-else/CheckEvenOdd.java): Check whether a number is even or odd using modulo operator

## How to Use

1. Open any Java file in your IDE
2. Read the comprehensive documentation block at the top of each file
3. Understand the algorithm approach, complexity analysis, and edge cases
4. Review the example usage in the main method
5. Run the program to see output

## Learning Path

- Start with **if-else** for basic conditional logic
- Progress to **loops** for iteration patterns
- Master **loop-in-loop** for nested patterns and 2D logic
- Learn **number manipulation** (countdigit, palindrome, reverse)
- Finish with **arrays** for advanced data structure manipulation techniques
